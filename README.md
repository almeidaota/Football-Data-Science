# Football Data Science

This was my first repository for studying data. It's just a few simple Jupyter notebooks, but I
have a soft spot for it: it's where I started asking questions about football with data, which
later grew into my undergraduate thesis
([sofascore-rating-prediction](https://github.com/almeidaota/sofascore-rating-prediction)).

## Notebooks

| Folder | Question |
|---|---|
| `Aproveitamento Brasileirão 2003-2022/` | How did home and away teams perform in the Brazilian Série A from 2003 to 2022? |
| `Aproveitamento Mando único São Paulo/` | Did the single-supporter rule (only home fans allowed) change results in São Paulo derbies, and how does it compare with other states? |
| `Goals 2014 - 2022/` | Goals in the Série A from 2014 to 2022. |

The CSV files in `Datasets/` cover Série A matches, goals, cards and team statistics. Column
descriptions (in Portuguese) are in `Datasets/Legenda.txt`.
